#### 🚀 Featured Project: Customer Health Scanner

A deployed application that scores customer risk two ways — a transparent rule-based model and a predictive model — then combines risk with predicted lifetime value to answer the question that matters: **which at-risk customers are really worth chasing, and is acting on it worth the cost?**

**Built with:** Python · Pandas · scikit-learn · SQL · DuckDB · Streamlit · Docker

🔗 [Repository](https://github.com/ameencode/customer-health-scanner) · 🚀 [Live App](https://customerhealth.streamlit.app)
